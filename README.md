# Social Links Profile

This is a solution to the **Social Links Profile** challenge from Frontend Mentor.

## Overview

A simple and clean profile card that displays:

* User avatar
* Name and location
* Short bio
* Social media links

The layout is fully responsive and works smoothly across mobile and desktop devices.

---

## Built With

* HTML5
* CSS3 (Flexbox)
* Responsive Design (using %, max-width, and viewport units)

---

## Responsive Design

The project was designed based on:

* Mobile: 375px
* Desktop: 1440px

Instead of fixed widths, the layout adapts using:

* width: 90%
* max-width: 320px
* min-height: 100vh
* Flexbox for centering

---

## What I Learned

* How to center elements using Flexbox
* The difference between px, %, and vh
* Building responsive layouts without relying heavily on media queries
* Writing cleaner and more maintainable CSS
